## Executive Summary

P3.6 implements the `list` CLI command, which queries the SQLite database for all stored studies and displays them in a formatted table (or JSON/CSV).

The list command is a read-only operation. It validates nothing, executes nothing, and modifies nothing. It retrieves study metadata from the persistence layer and formats it for the user.

P3.6 is the first CLI command that exercises the **read path** of the persistence layer. While P3.5 (run) exercises the write path (create plan, execute, persist), P3.6 validates that stored data can be retrieved, filtered, sorted, and displayed.

---

## Architectural Constraints

- **No frozen domain changes.** All code lives in the CLI layer (`src/cli/commands/`). No `engine.*`, `research.*`, or `infrastructure.*` files are modified; only their frozen public APIs are consumed.
- **No frozen P3.4/P3.5 changes.** Do not modify `validate_command.py` (P3.4 frozen) or `run_command.py` (P3.5 frozen).
- **`cli.builders` is shared and evolvable.** If the list command needs new builder functions, add them to `cli.builders` — do not duplicate logic across commands.
- **Persistence read-only.** Use `create_persistence_context()` from P3.2 to obtain the persistence context. Query only — no writes.
- **No YAML parsing.** The list command takes no file argument. It operates entirely on stored database state.
- **Output format is command-specified.** The list command defines its own formatters (table, JSON, CSV). Do not depend on P3.7 (export) output formatters — those handle full result data, not study metadata.
- **Exit codes:** 0 for success, 1 for database error, 130 for interruption.

### 2. Output format specifications

**Table format** (default):

```
Study ID        │ Name                    │ Version │ Status    │ Units │ Date Created
────────────────┼─────────────────────────┼─────────┼───────────┼───────┼──────────────
study-abc123    │ Part 19 Glidepaths      │ 1.0     │ completed │ 1,728 │ 2026-07-20
study-def456    │ Part 40 De-risking      │ 1.0     │ completed │   864 │ 2026-07-19
study-ghi789    │ Dynamic Withdrawals     │ 1.0     │ failed    │ 2,160 │ 2026-07-18

Total: 3 studies
```

**JSON format:**

```json
{
  "studies": [
    {
      "study_id": "study-abc123",
      "name": "Part 19 Glidepaths",
      "version": "1.0",
      "status": "completed",
      "units": 1728,
      "created_at": "2026-07-20"
    }
  ],
  "total": 3
}
```

**CSV format:**

```csv
study_id,name,version,status,units,created_at
study-abc123,Part 19 Glidepaths,1.0,completed,1728,2026-07-20
study-def456,Part 40 De-risking,1.0,completed,864,2026-07-19
study-ghi789,Dynamic Withdrawals,1.0,failed,2160,2026-07-18
```

### 3. COMMANDS registration

In `src/cli/commands/__init__.py`, add:

```python
from cli.commands.list_command import ListCommand
COMMANDS["list"] = ListCommand
```

### 4. Error handling

| Condition | Exit Code | Behavior |
|-----------|-----------|----------|
| Database unreachable | 1 | Print error, return ERROR |
| No studies found | 0 | Print "No studies found" message, return SUCCESS |
| KeyboardInterrupt | 130 | Print interruption message |
| Successful listing | 0 | Print formatted study list |
