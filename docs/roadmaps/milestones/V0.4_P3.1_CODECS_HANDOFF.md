## Executive Summary

P3.1 is the first implementation package of Phase 3. It provides concrete implementations of the three protocols that `PersistenceReconstructionContext` requires. Once this package is complete, the persistence layer can be used outside tests without test-dummy codec implementations.

This unblocks every downstream package in Phase 3 (`run`, `list`, `export`, `optimize`, `compare`) — all require a fully constructed reconstruction context to interact with the database.

---

## Architectural Constraints

- **No frozen domain changes.** All codecs live in the infrastructure layer (`src/infrastructure/persistence/`). No `engine.*` or `research.*` files are modified; only their public APIs are consumed.
- **No behavioral changes to `SQLiteRepository`.** The codecs must satisfy the existing protocol contracts exactly.
- **No test-dummy code in production.** Concrete codecs must not import or reference test-only classes.

---

## What Must Exist

### Three protocol implementations

**DatasetResolver** (protocol at `src/infrastructure/persistence/sqlite_repository.py:131`)
- `resolve(dataset_identifier: str) -> Dataset`
- Returns a `Dataset` object for valid identifiers.
- Raises a `RepositoryError` subclass for unknown identifiers.

**PolicyCodec** × 2 (protocol at `sqlite_repository.py:136`)
- One codec for `AllocationPolicy`-compatible objects.
- One codec for `WithdrawalPolicy`-compatible objects.
- `dump(policy) -> Mapping[str, JSONScalar]`
- `load(parameters) -> policy` instance of the same dumped type.
- Round-trip: `load(dump(policy))` produces a `isinstance`-equivalent object.

**SimulationResultCodec** (protocol at `sqlite_repository.py:152`)
- `dump(result) -> SerializedSimulationResult`
- `load(statistics_payload_json, monthly_payloads_json) -> SimulationResult`
- Lossless preservation: all `Decimal` precision, `date` values, booleans, integers, strings.
- Monthly payload order preserved.

### Public API exports

Add new codec classes to `src/infrastructure/persistence/__init__.py`.

### Tests

Cover the following behaviors:

| Behavior | Description |
|----------|-------------|
| Reconstruction context creation | `PersistenceReconstructionContext` with concrete codecs constructs without error |
| Dataset resolution | Valid identifier → `Dataset`; unknown identifier → `RepositoryError` |
| Policy round-trip | `AllocationPolicy`-compatible object survives dump → load |
| Policy round-trip | `WithdrawalPolicy`-compatible object survives dump → load |
| Simulation result round-trip | `SimulationResult` survives dump → load with identical fields |
| Decimal precision | Decimal values survive round-trip without precision loss |
| Month ordering | Monthly payload order preserved through dump → load |
| SQLiteRepository integration | Full save/load cycle with `SQLiteRepository` using concrete codecs succeeds |
